This project is an object-\/oriented C++ implementation for solving the one-\/dimensional heat equation using various finite difference methods, as part of the Cranfield University "{}\+Computational Methods \& C++"{} assignment.\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Problem Description}{Problem Description}}\label{index_autotoc_md1}
The project aims to compute the temperature distribution over time within a 31cm thick wall.


\begin{DoxyItemize}
\item {\bfseries{Governing Equation\+:}} $\frac{\partial T}{\partial t}=D\frac{\partial^{2}T}{\partial x^{2}}$
\item {\bfseries{Physical Properties\+:}}
\begin{DoxyItemize}
\item Wall Thickness ( $L$)\+: 31 cm
\item Thermal Diffusivity ( $D$)\+: 93 cm²/hr
\item Uniform Initial Temperature ( $T_{in}$)\+: 38°C
\item Maintained Surface Temperature ( $T_{sur}$)\+: 149°C
\end{DoxyItemize}
\item {\bfseries{Numerical Methods to Implement\+:}}
\begin{DoxyEnumerate}
\item Du\+Fort-\/\+Frankel (Explicit)
\item Richardson (Explicit)
\item Laasonen (Implicit)
\item Crank-\/\+Nicholson (Implicit)
\end{DoxyEnumerate}
