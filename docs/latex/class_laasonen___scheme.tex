\doxysubsection{Detailed Description}
Implements the Laasonen implicit numerical scheme. 

The Laasonen scheme is a fully implicit method (backward in time, central in space). It is unconditionally stable and first-\/order accurate in time, second-\/order in space. It requires solving a tridiagonal system of linear equations at each time step.
