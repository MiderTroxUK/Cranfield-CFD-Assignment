\doxysubsection{Detailed Description}
Base class for numerical schemes. 

This class serves as a parent class for all specific numerical schemes (e.\+g., Dufort-\/\+Frankel, Richardson, Laasonen, Crank-\/\+Nicholson). It holds common parameters like grid spacing, time step, and material properties.
