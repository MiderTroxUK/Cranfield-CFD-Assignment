Detailed Description

Implements the Crank-Nicholson implicit numerical scheme.

The Crank-Nicholson scheme is a semi-implicit method (average of forward and backward time steps). It is unconditionally stable and second-order accurate in both time and space. It requires solving a tridiagonal system of linear equations at each time step.
