Detailed Description

Provides methods for verifying numerical results and conditions.

This class includes utilities to check the stability of numerical schemes and calculate error norms (e.g., L2 norm) by comparing numerical results with analytical solutions.

Calculates the L2 Norm (Discrete Integral) between numerical and analytical solutions.

Formula: sqrt( sum( (num[i] - ana[i])^2 ) * dx )
